# Техническое задание: Платформа многоканальных уведомлений

## Цель

Django-сервис для создания, планирования и доставки уведомлений через Email, SMS и Telegram.

## Функциональные требования

- Создавать уведомление для одного или нескольких получателей.
- Позволять задать порядок каналов доставки.
- В режиме fallback переходить к следующему каналу после неудачи предыдущего.
- Поддержать отправку только по выбранному каналу.
- Хранить общий статус уведомления и каждую попытку доставки.
- Отправлять задачи асинхронно и поддержать синхронный локальный режим.
- Обрабатывать статусы провайдеров через webhooks.
- Предоставить web-панель, REST API, Swagger и GraphQL.
- Собирать базовые метрики и поддержать контейнерный запуск.

## Технические требования

- Django, DRF, Celery, Redis, PostgreSQL/SQLite, GraphQL и Docker.
- Провайдеры работают через адаптеры и mock-режим.
- Токены и пароли задаются только через окружение.
